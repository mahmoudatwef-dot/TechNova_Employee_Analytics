# TechNova Employee Analytics

A complete Employee Analytics project built using PostgreSQL, SQL, and Power BI.

## Project Overview

TechNova Employee Analytics is a data analytics project designed to analyze employee data and provide useful business insights related to workforce, salaries, performance, attendance, and employee attrition.

## Tools & Technologies

- PostgreSQL
- SQL
- Power BI
- DAX
- GitHub

## Database

The project uses a PostgreSQL database containing four main tables:

- Employees
- Departments
- Performance
- Attendance

The database was designed using primary keys and foreign keys to establish relationships between the tables.

## SQL Analysis

The project includes SQL analysis for:

- Total number of employees
- Average salary
- Salary distribution
- Salary by department
- Total payroll
- Employee performance
- Attendance and absence rates
- Employee attrition
- Hiring trends
- Data quality and validation

## Power BI Dashboard

The Power BI dashboard provides an interactive overview of the company's workforce.

### Key KPIs

- Total Employees
- Average Salary
- Total Payroll
- Attrition Rate

### Dashboard Analysis

- Employees by Department
- Average Salary by Department
- Employees Hired Over Time
- Attrition Rate by Department
- Average Performance by Employee
- Attendance Status
- Salary Level Distribution
